# Sisaket Data Dashboard (VS Code)

โปรเจกต์ Dashboard สำหรับอ่านข้อมูลจาก Google Sheets แท็บ `sisaketdata` ผ่าน Google Apps Script Web App

## โครงสร้างไฟล์

```text
sisaket-dashboard-vscode/
├── index.html
├── styles.css
├── app.js
├── config.js
├── sample-data.js
├── README.md
└── gas/
    ├── Code.gs
    └── appsscript.json
```

## 1) ตั้งค่า Google Apps Script

1. เปิด Google Sheet:
   https://docs.google.com/spreadsheets/d/1kxgE7MMUxwRO1nb_jEK-WpyzrFuycZWyBkv0nCf_Ug8/edit
2. ตรวจสอบว่าชื่อแท็บด้านล่างเป็น `sisaketdata` ตรงตามนี้ (ไม่ใช่แค่ชื่อไฟล์ Google Sheet)
3. ไปที่ **Extensions > Apps Script**
4. วางเนื้อหาไฟล์ `gas/Code.gs` ลงใน `Code.gs`
5. ใน Apps Script ไปที่ **Project Settings** แล้วเปิดการแสดงไฟล์ `appsscript.json` หากยังไม่แสดง จากนั้นแทนที่ด้วยไฟล์ในโฟลเดอร์ `gas`
6. กด Save
7. เลือกฟังก์ชัน `testConnection` แล้วกด Run เพื่ออนุญาตสิทธิ์และตรวจสอบข้อมูล
8. เลือก **Deploy > New deployment > Web app**
9. Execute as: **Me**
10. Who has access: เลือกตามนโยบายข้อมูลของหน่วยงาน (ดูคำเตือนด้านความปลอดภัยด้านล่าง)
11. กด Deploy และคัดลอก URL ที่ลงท้ายด้วย `/exec`

## 2) ตั้งค่าเว็บใน VS Code

เปิด `config.js` แล้วใส่ URL ที่คัดลอกได้:

```js
window.APP_CONFIG = {
  API_URL: "https://script.google.com/macros/s/ใส่_DEPLOYMENT_ID/exec",
  REFRESH_INTERVAL_MS: 15000
};
```

`15000` คือรีเฟรชทุก 15 วินาที (หน่วยมิลลิวินาที)

## 3) เปิดเว็บ

1. เปิดโฟลเดอร์โปรเจกต์นี้ใน VS Code
2. ติดตั้ง Extension ชื่อ **Live Server**
3. คลิกขวา `index.html` แล้วเลือก **Open with Live Server**

เมื่อยังไม่ใส่ API URL เว็บจะใช้ข้อมูลตัวอย่างจาก CSV ที่แนบมา (80 แถว) ให้ก่อน
เมื่อใส่ URL แล้ว เว็บจะอ่านข้อมูลจาก Google Sheet และรีเฟรชอัตโนมัติตามช่วงเวลาที่ตั้งไว้

## 4) รูปแบบข้อมูลใน Google Sheet

แถวแรกต้องเป็นหัวคอลัมน์ โดยรองรับชื่อหลักดังนี้:

| คอลัมน์ | ชื่อหัวตาราง |
|---|---|
| ปี | `ปี` |
| อำเภอ | `อำเภอ` |
| หมู่บ้าน/ชุมชน | `หมู่บ้าน/ชุมชน` |
| ผู้ป่วยเข้ารับบำบัด | `ผู้ป่วยเข้ารับบำบัด` |

สามารถมีคอลัมน์อื่นเพิ่มได้ ระบบจะอ่านเฉพาะคอลัมน์ที่ต้องใช้

## 5) ความปลอดภัยที่ต้องอ่านก่อน Deploy

- Apps Script ในตัวอย่างตั้งให้รันในสิทธิ์เจ้าของสคริปต์ และไฟล์ manifest ตั้ง `ANYONE` เพื่อให้เว็บหน้า VS Code เรียก API ได้โดยไม่ต้องล็อกอิน
- **อย่าใช้การเข้าถึงแบบ Anyone หากชีตมีชื่อ-นามสกุล เลขบัตรประชาชน ข้อมูลสุขภาพรายบุคคล หรือข้อมูลที่ระบุตัวบุคคลได้** เพราะผู้ที่มี URL อาจอ่านข้อมูลที่ API ส่งออกได้
- โค้ด API นี้ส่งออกเฉพาะ 4 ฟิลด์สรุปตามอำเภอ/ปี ไม่ได้ส่งคอลัมน์อื่น แต่ต้องตรวจสอบข้อมูลและสิทธิ์การเผยแพร่ของหน่วยงานก่อน Deploy
- หากข้อมูลเป็นข้อมูลภายใน ให้จำกัดสิทธิ์การเข้าถึง และใช้งานภายในบัญชี/โดเมนองค์กรตามนโยบาย IT แทนการเปิดสาธารณะ
- ไม่ควรใส่รหัสผ่านหรือ secret key ลงใน `config.js`

## หมายเหตุ

ลิงก์ Google Sheet ที่ได้รับไม่สามารถอ่านเนื้อหาจริงจากระบบนี้ได้โดยตรง จึงสร้างโค้ดให้เชื่อมด้วย Spreadsheet ID และชื่อแท็บ `sisaketdata` ตามที่แจ้ง และใช้ CSV ที่แนบมาเป็นข้อมูลตัวอย่างสำหรับทดสอบหน้าตาเว็บ
